# Expense Tracker App for Android

Приложение для учёта доходов и расходов на Python с использованием Kivy/KivyMD.

## Функционал

✅ **Множественные счета** - создание, переименование и удаление счетов
✅ **Доходы и расходы** - добавление транзакций с категориями
✅ **Эмодзи категории** - визуальное отображение категорий (🍔 Еда, 🚗 Транспорт, 💼 Зарплата и т.д.)
✅ **История операций** - просмотр всех транзакций с поиском
✅ **Тёмная тема** - современный дизайн в тёмных тонах
✅ **Навигация** - возврат на главный экран из любой вкладки
✅ **SQLite база данных** - сохранение всех данных локально

```
/workspace/
```

## Установка зависимостей

Для запуска на компьютере:

```bash
pip install kivy kivymd
```

## Запуск приложения

```bash
python main.py
```

## Сборка APK для Android

Для сборки APK файла используйте Buildozer:

```bash
# Установите buildozer
pip install buildozer

# Инициализируйте (если нет buildozer.spec)
buildozer init

# Соберите APK
buildozer android debug

# Или сразу релизную версию
buildozer android release
```

## Особенности приложения

### Главный экран
- Отображение общего баланса
- Быстрый доступ к добавлению доходов/расходов
- Нижняя навигационная панель

### Счета
- Создание новых счетов
- Переименование существующих
- Удаление счетов с историей операций
- Просмотр баланса каждого счёта

### Добавление транзакции
- Выбор типа (доход/расход)
- Выбор счёта
- Выбор категории с эмодзи
- Ввод суммы и описания

### История операций
- Полный список всех транзакций
- Поиск по категориям и описанию
- Цветовая индикация (зелёный - доход, красный - расход)

### Настройки
- Переключение темы (тёмная/светлая)
- Управление категориями
- Экспорт данных
- Очистка всех данных
